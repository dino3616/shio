## About の素材: 人格メモ

普段使っている LLM(なぴ)による本人の人格分析。About の文章を書くときの原料。

### 要素の抜き出し

- **矛盾をそのまま抱えたまま、意味に変えようとする人**
- 繊細に人や場の空気を見る。迷ったとき流されず「これはどういう構造なんだろう」と考え直す
- 創作と言葉のセンス。意味だけでなく文字列の構造まで遊ぶ。感情を直接説明せず、少しずらした言葉で残す
- 「おしゃれ」より**世界観を作ること**が好き
- 自分に厳しい。自己分析が自己処罰に変わる瞬間がある
- 人付き合いの難しさを感じているからこそ、**「ちゃんとつながりたい」への執着が強い**

### 自己紹介文の候補(なぴ案)

仕事寄り:

> 人や物事の中にある違和感や矛盾を拾って、言葉や表現にするのが好きです。
> デザイン、音楽、服、文章など手段は違っても、「その人らしさ」や「まだ名前のない感覚」を形にすることに惹かれます。

人格寄り:

> 好奇心は強いけれど、考えすぎるところがあります。
> 人との距離感に悩むことも多い一方で、結局ずっと人に興味があります。
> 自分の中の矛盾も含めて、面白がりながら表現していきたいです。

### 扱いの指針

- 仕事用ポートフォリオでは「生きづらさ」を前面に出しすぎない。内面の深さは残しつつ、**観察力・言語化・世界観づくり・人への興味**に翻訳する
- デザインディレクションとの整合: コンセプトキーワードの「かわいくて、不穏」「日常のとなりの宇宙」はどちらも**矛盾の同居**。「矛盾を抱えたまま意味に変える」という人格が、サイトの見た目そのものに現れている構造になっている。About の文章はこの接続を活かせる(自分の説明とサイトの世界観が一枚につながる)

## 更新頻度の高いコンテンツ(プレイリスト・メイク)

**Logs セクション**に載せる。載せたいもの:

1. **プレイリスト** — 曲が好き。聴いているもので人柄を伝える
2. **スキンケア手順・メイク手順** — メイクが好き。手順やアイテムを紹介

要件:

- 更新のたびに commit / デプロイはしない(コンテンツをリポジトリに置かない)
- 管理画面も作らない。**更新のインターフェースは LLM**(チャットで「この曲追加して」で終わり)

実現方式(DB + 自作 MCP サーバー)は [`architecture.md`](architecture.md) を参照。
