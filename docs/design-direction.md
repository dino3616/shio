# デザインディレクション

Figma のムードボード([リンク](https://www.figma.com/design/sdp2RPY3x1ysSxQd6LtWra?node-id=158-17)、image 1〜30)の分析から抽出した方向性。2026-08-07 時点。

方向性を一言で: **ミニマル上品系ではなく、密度と遊びで人柄を伝える。**

## 制作フロー(決定: 実装先行)

Figma で静的モック([🛸 Website Mock](https://www.figma.com/design/sdp2RPY3x1ysSxQd6LtWra?node-id=226-3))を作ってみた結果、**このデザインの価値(流体グラデーション・数学的モーション・視線追従・グリッチ)はすべてランタイムの現象で、静的な画面では原理的に表現できない**と確認した。Figma を磨くのはやめ、ブラウザで直接デザインする。

- Figma モックは「6 セクション構成・7 色パレット・フォント 4 役」の確認メモとして凍結。これ以上磨かない
- 最初に作るのは **Hero の流体グラデーションシェーダー**。世界観の核を先に完成させ、それを基準に全体のトーンを決める
- 骨格コンポーネントは **21st.dev** 等のレジストリ(shadcn 形式、ソースがリポジトリに落ちてくる)から取り込み、色・フォント・モーションを自分の言語に書き換える。姉妹格: reactbits、Magic UI
- レジストリ互換のため **Tailwind CSS を採用**。アニメーションの基盤は **Motion**(旧 Framer Motion)+ 自作 rAF / シェーダー
- 借り物をそのまま使うと「テンプレっぽさ」が戻ってくるので、取り込んだコンポーネントは必ずファインチューンしてから使う

## コンセプトキーワード

迷ったらこの3語に照らして判断する。3つ同時に満たす必要はなく、どれか1つに強く効いていればOK。

### 1. かわいくて、不穏(CREEPY-CUTE)

ボードの最重要軸。かわいさには必ず毒・違和感・壊れがセットになる。純度100%のかわいいは選ばれていない。
参照: img 5, 6, 12, 13, 15, 27

### 2. 壊れたレトロテック(GLITCH NOSTALGIA)

ブラウン管・レトロPC・エラーダイアログ・ピクセルノイズ。エンジニアという肩書きと直結する、機能する装飾。
参照: img 10, 12, 13, 20, 29

### 3. 日常のとなりの宇宙(EVERYDAY COSMIC)

洗濯機の中の宇宙飛行士、ハートの月、水没した階段。現実が数センチだけズレる感覚。ユーモアの受け皿でもある。
参照: img 7, 17, 18, 22, 23, 24

## エンジニア×デザイナーだからできる演出

既製テンプレートでは再現できない、実装力が前提の表現。それ自体が「両方できる」ことの証明=ポートフォリオの一部になる。

| 演出                   | 内容                                                                                                            | 実装の当たり                                                               |
| ---------------------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 流体グラデーション     | 不規則かつ流動的に動く色面。img 26, 30 のマーブル模様を生きた背景に。ノイズ関数由来なので二度と同じ絵にならない | WebGL フラグメントシェーダー + シンプレックスノイズ(GLSL / three.js)       |
| 数学的モーション       | リサージュ曲線を漂う星、バネ物理で追従する目玉、設計したカスタムイージング。式で気持ちよさを作る                | requestAnimationFrame 自作 / Motion(決定済みの基盤)/ GSAP、減衰振動・atan2 |
| 空間的な奥行き         | 傾いた月・CRT・チェーンが層になって浮かび、スクロールとマウスで視差が付く。平面のコラージュに z 軸を足す        | CSS 3D transform + perspective / three.js、スクロール連動パララックス      |
| 実世界との連動         | 訪問した時刻で空の色と月相が変わる、天気で演出が変わる、いま聴いてる曲が流れ込む。訪れるたびに違うサイトになる  | 月齢計算・Date / 天気API / Spotify(Last.fm)API                             |
| 視線のインタラクション | ページ中の目玉が訪問者のカーソルを追いかける。「かわいくて、不穏」を体験として実装する、二大モチーフ直結の演出  | ポインタ座標から atan2 で回転角を算出。低負荷なので多用できる              |
| グリッチ               | ホバーで RGB ずれ・走査線・ピクセル崩れが起きて、離すと直る。壊れたレトロテック軸の主演出                       | SVG filter(feDisplacementMap)/ canvas / シェーダー                         |

**盛りすぎ注意**: 全部を同時に使うと散らかる。各セクション主演出1つまで(例: Hero=流体グラデーション+奥行き、Works=グリッチ、Contact=実世界連動)。`prefers-reduced-motion` への対応も入れると、演出過多サイトとの決定的な差になる。

## モチーフの質感方針(決定)

初期実装のモチーフ(目玉・ハート・星)が「チープ=紙っぺら」に見えた原因は、**シェーダー背景とモチーフの質感の解像度差**。背景はテクスチャと有機的な複雑さを持つのに、モチーフがフラットな単色ベクターだったため、レイヤーが馴染まなかった。

検討した3案と結論:

| 案                                       | 判断           | 理由                                                       |
| ---------------------------------------- | -------------- | ---------------------------------------------------------- |
| エフェクトで誤魔化す(ブラー・グロー盛り) | 却下           | 形の言語が安いままだと濁るだけ。根本解決にならない         |
| チープさを活かす(ステッカー/コラージュ)  | 一部採用       | 「傾いて浮かぶコラージュ」という配置の言語として維持       |
| モチーフの質感を上げる                   | 主軸として採用 | 内部をプロシージャルに描き込み、背景と質感の解像度を揃える |

具体的な実装(すべてコード生成=エンジニア×デザイナーの証明):

- **全画面フィルムグレイン**: `feTurbulence` のノイズを `mix-blend-overlay` で全画面に薄く重ね、全レイヤーを1枚のコラージュに統一する(最重要。質感差を埋める接着剤)
- **目玉**: 虹彩の繊維64本をシード付き乱数で生成(SSR/CSR一致)、血管・角膜反射・眼窩の落ち影を追加
- **月**: `feTurbulence` + `feDiffuseLighting` で月面の凹凸、クレーターと海、ターミネーター(欠け際の影)
- **星**: グロー(radial gradient)→ クロスフレア(4芒星)→ 白いコアの三層描画 + 背景の星屑で奥行き
